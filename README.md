# NewsFlow Studio

Приложение для подготовки новостных сценариев и автоматического монтажа роликов из большой локальной библиотеки футажей.

## Как устроен монтаж

1. В разделе **Футажи** добавьте одну или несколько папок и нажмите **ИИ-индексация**.
2. NewsFlow извлечёт три кадра из каждого клипа, создаст визуальный CLIP-вектор и сохранит индекс в `%LOCALAPPDATA%\NewsFlow\footage-index.sqlite3`.
3. В разделе **Монтаж** вставьте текст диктора или готовый сценарий и нажмите **Черновой монтаж**.
4. Агент разобьёт текст на сцены и сформулирует визуальный запрос. Локальный индекс подберёт подходящие клипы по изображению, а не только по имени файла.
5. Проверьте результат во встроенном плеере. Клипы можно заменить, переставить, удалить, оценить и сохранить как проект.
6. Добавьте готовую озвучку: длительность сцен автоматически подгоняется под неё. Затем экспортируйте MP4.

## План идей и маршруты ИИ

В **Подготовка → Генерация идей** задайте общий план выпуска, например 100 роликов. Добавляйте направления кнопкой `+ В план`, указывайте число идей для каждого направления и меняйте его двойным щелчком в таблице. В план можно включить и собственные идеи отдельной галочкой.

Для каждого направления сохраняются маршрут и требования: выбранная Chrome-сессия Claude и ссылка на нужный чат либо конкретный OpenAI API-ключ. При исчерпании лимита Claude NewsFlow переходит к следующей активной Chrome-сессии, затем к активным ключам OpenAI API. API не продолжает обычный чат ChatGPT по URL; постоянный контекст в этом режиме задаётся сохранённым промптом направления.

## Озвучка

Раздел **Производство → Озвучка** объединяет возможности Войсер 0.4.10 в NewsFlow:

- **Создать озвучку** — текст сценария, профиль диктора и создание MP3;
- **Голоса и API** — зашифрованный Windows API-ключ Secret Voicer, Voice ID, стабильность, сила эмоций и каталог голосов;
- **Готовые MP3** — прослушивание и передача выбранной озвучки сразу в монтаж.

Длинный текст автоматически разбивается на части до 4000 символов. Голосовой API-ключ хранится в настройках в зашифрованном виде Windows DPAPI.

## Подготовка 20 000 клипов

- Шесть секунд без звука — хороший исходный формат.
- Не нужно вручную перекодировать уже собранную библиотеку и выравнивать битрейт.
- При экспорте NewsFlow сам создаёт постоянные прокси только для реально выбранных фрагментов: H.264, CFR 30 fps, `yuv420p`, нужное разрешение и формат кадра.
- Прокси хранятся в `%LOCALAPPDATA%\NewsFlow\RenderProxy` и повторно используются, поэтому последующие сборки быстрее.
- Для новых внешних нарезок желательно использовать H.264, постоянные 30 fps и `yuv420p`, но это рекомендация, а не обязательное условие. Фиксированный одинаковый битрейт не нужен.

## Интернет и YouTube

- Сначала используется локальная библиотека.
- Если уверенность подбора ниже порога, NewsFlow может автоматически загрузить материал из Wikimedia Commons и добавить его в индекс.
- Автоматический YouTube-поиск выключен по умолчанию и включается отдельно в монтажере. Агент проверяет несколько моментов найденного ролика через CLIP и загружает шестисекундный отрезок около лучшего визуального совпадения, а не первые секунды или весь ролик.
- При ручном поиске можно выбрать ролик и указать начало нужного фрагмента.
- URL источника и сведения о лицензии сохраняются внутри библиотеки. Видимые подписи «Архивные кадры» и «Иллюстративное видео» на ролик не добавляются.
- Пользователь отвечает за наличие разрешения на повторное использование скачанного материала.

## Обучение агента

Обучать отдельную нейросеть с нуля не требуется. Визуальная модель уже понимает общие объекты, места и типы сцен. Кнопка 👍 повышает приоритет выбранного клипа и мягко усиливает визуально очень похожие футажи. Кнопка 👎 исключает только выбранный клип из автоматического подбора.

ИИ-индексация использует многопоточный процессор. Видеопрокси и финальный экспорт используют NVIDIA NVENC при его наличии и автоматически переходят на программный H.264, если аппаратный кодировщик недоступен.

При первом запуске ИИ-индексации модели CLIP загружаются в `%LOCALAPPDATA%\NewsFlow\models`. После этого они работают локально.
