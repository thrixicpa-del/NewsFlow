Политика конфиденциальности

Дата публикации: 31 августа 2026 года.

1. Что делает NewsFlow

NewsFlow — локальное настольное приложение. Оно помогает оператору подготовить ролики, распределить их по подключённым каналам, настроить расписание и просмотреть доступную аналитику YouTube.

2. Какие данные могут быть доступны

После добровольного входа оператора через Google OAuth NewsFlow может получать данные, необходимые для выбранных функций: название и идентификатор канала, аватар, количество подписчиков, сведения о видео, метаданные публикации и показатели аналитики.

Для работы с каналом используются YouTube Data API и YouTube Analytics API. Право на финансовые показатели запрашивается отдельно только если оператор явно выбирает функцию дохода.

3. Для чего используются данные

  • для отображения подключённого канала и его доступной аналитики;
  • для подготовки черновой загрузки ролика, названия, описания, тегов и времени публикации;
  • для связывания опубликованного ролика с темой, сценарием и SEO-пакетом NewsFlow.

NewsFlow не использует доступ к Google для рекламы, продажи пользовательских данных или предоставления доступа третьим лицам.

4. Где хранятся данные

Токены OAuth, настройки каналов, очередь публикаций и связанные метаданные хранятся локально на компьютере оператора в данных приложения NewsFlow. Этот сайт не собирает и не получает OAuth-токены, пароли Google или содержимое каналов.

5. Управление доступом и удаление

Оператор может удалить канал из NewsFlow, очистить его профиль входа и отозвать выданный доступ в настройках Google Аккаунте. После удаления локального профиля NewsFlow прекращает использовать сохранённый для него токен.

6. Срок хранения

Данные хранятся на устройстве оператора, пока он не удалит канал, очередь, настройки приложения или само приложение. Google самостоятельно регулирует срок действия и отзыв OAuth-разрешений.
