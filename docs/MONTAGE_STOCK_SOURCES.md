# Стоковые источники монтажа

В настройках «Монтаж» выберите «Источники футажей»:

- **Локальная библиотека** — использовать только ваши проиндексированные файлы.
- **Библиотека + стоки** — сначала точные локальные совпадения, затем разрешённые
  стоковые видео; при нехватке — подходящий локальный контекст.
- **Только стоки** — видео из выбранных источников, затем подходящие изображения
  с плавной анимацией, если видео не нашлись.

Отметьте разрешённые источники или «Все вместе». Pexels, Pixabay и Coverr требуют
собственные API-ключи; Wikimedia Commons и NASA работают без ключей. В разделе
ключей выберите провайдера, вставьте по одному ключу на строку и добавьте.
Количество строк не ограничено. Можно выключать и удалять отдельные записи.
После сохранения секреты не показываются; Windows защищает их в настройках.
Параллельные запросы распределяются между провайдерами, а доступные ключи
последовательно и справедливо чередуются между запросами и задачами. Лимиты
сервиса и паузы после 429 действуют на все его ключи.

«Обрезать стоковые видео» создаёт отдельные короткие фрагменты. Если выключить,
скачанный оригинал используется напрямую, а границы показа задаёт существующий
таймлайн по озвучке. Исходный файл не меняется в обоих случаях. Оригинальный звук
стоков в итоговый ролик не попадает.

Существующий процент уникальности и его диапазоны работают во всех режимах.
Настройки повторного использования не разрешают неподходящие кадры: CLIP и
смысловые ограничения проверяют выбранный фрагмент. При исчерпании вариантов
проект сохраняет отмеченные сцены для ручной замены и не выдаёт успешный MP4.
Повторный экспорт сохранённого проекта сохраняет выбранные материалы и политику
источников; исправные ручные замены заново не подбираются.

Рядом с MP4 сохраняются `.stocks.txt` и `.stocks.json`: авторы, источник, лицензия
и изменения каждого использованного материала. При передаче ролика сохраняйте
эти сведения и выполняйте условия указанных лицензий. Архивные материалы нужно
обозначать в сценарии; наличие похожего кадра не подтверждает конкретное событие.

Commons поддерживает CC0, public domain и CC BY; SA/NC/ND и неизвестные условия
отклоняются. NASA принимается только при явных подходящих условиях конкретного
материала, поэтому многие результаты не будут доступны. Coverr используется для
видео. Источники, отключённые галочками, не используются даже из кэша.

Официальные документы:
[Pexels](https://www.pexels.com/api/documentation/),
[Pixabay](https://pixabay.com/api/docs/),
[Coverr](https://api.coverr.co/docs/videos/),
[Commons](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia),
[NASA](https://www.nasa.gov/nasa-brand-center/images-and-media/).
