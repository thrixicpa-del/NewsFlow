# Стоковые источники монтажа

В настройках «Монтаж» выберите «Источники футажей»:

- **Локальная библиотека** — использовать только ваши проиндексированные файлы.
- **Библиотека + стоки** — сначала точные локальные совпадения, затем разрешённые
  скачанные материалы и стоковые видео; при нехватке — подходящий локальный
  контекст или лицензированные изображения с плавной анимацией.
- **Только стоки** — видео из выбранных источников, затем подходящие изображения
  с плавной анимацией, если видео не нашлись.

Галочка **«Использовать стоки с моими футажами»** выбирает тот же режим
«Библиотека + стоки». Снятие галочки возвращает к локальной библиотеке;
режим «Только стоки» доступен в списке.

Отметьте разрешённые источники или «Все вместе». Pexels, Pixabay и Coverr требуют
собственные API-ключи; Wikimedia Commons и NASA работают без ключей. В разделе
ключей выберите провайдера, вставьте по одному ключу на строку и добавьте.
«Все вместе» не заменяет API-ключи: без них Pexels, Pixabay и Coverr пропускаются.
Поиск продолжается через Wikimedia Commons и допустимые материалы NASA.
Количество строк не ограничено. Можно выключать и удалять отдельные записи.
После сохранения секреты не показываются; Windows защищает их в настройках.
Параллельные запросы распределяются между провайдерами, а доступные ключи
последовательно и справедливо чередуются между запросами и задачами. Лимиты
сервиса и паузы после 429 действуют на все его ключи.

Галочка **«Использовать библиотеку скачанных стоков»** включена по умолчанию.
Под ней показан полный путь к папке `Стоки` внутри выбранной папки загрузок.
Сначала проверяются уже скачанные материалы по всем формулировкам сцены и
синонимам, затем выполняется новый поиск. Источники, лицензии, CLIP и смысловые
ограничения действуют и для этой библиотеки. Отключение галочки убирает
предпочтение библиотеки: поиск снова начинается с провайдеров, но повторно
скачивать тот же исправный оригинал не требуется. Галочка не удаляет файлы.
Перед ручной очисткой завершите задачи и учтите ссылки сохранённых проектов;
после удаления недоступные источники нужно восстановить или заменить.

Поиск не обрезает список формулировок до десяти: исходный запрос, готовые
планировочные варианты, конкретные синонимы и контекст проходят без дубликатов.
Перебор конечный и останавливается после подходящего набора. Новая карта сцен
не создаётся. При нехватке точных материалов используются только допустимые
сюжетно близкие кадры, включая ранее скачанные.

Для нейтральных иллюстраций важнее соответствие словам: причал, насос, склад
или другой нужный объект может быть снят в другой стране. Сама страна съёмки
не повод отклонять подходящий материал. Когда сцена называет конкретного
человека, флаг, место или событие, сохраняется точная привязка; общая иллюстрация
не выдаётся за документальную запись этого события. Это правило уточнено
владельцем 20.10.2026 и сохранено также в `AGENTS.md`.

История принятых проектов сохраняется рядом с подготовленными стоками в
`prepared/selection-usage.sqlite3`. Она учитывает источник, исходный временной
фрагмент и положение (начало, середина, конец). В похожих следующих роликах
предпочтение получают менее использованные подходящие источники и интервалы;
при разрешённых повторах внутри одного ролика чередуется весь доступный пул.
Положение меняется только между сценами, для которых кадры подходят по смыслу.
При малой библиотеке повторы неизбежны; процент уникальности не отменяется.
Повторный экспорт уже сохранённого проекта заново не переставляет его кадры.

«Обрезать стоковые видео» создаёт отдельные короткие фрагменты. Если выключить,
скачанный оригинал используется напрямую, а границы показа задаёт существующий
таймлайн по озвучке. Исходный файл не меняется в обоих случаях. Оригинальный звук
стоков в итоговый ролик не попадает.

Существующий процент уникальности и его диапазоны работают во всех режимах.
Настройки повторного использования не разрешают неподходящие кадры: CLIP и
смысловые ограничения проверяют выбранный фрагмент. При исчерпании вариантов
проект сохраняет отмеченные сцены для ручной замены и не выдаёт успешный MP4.
Повторный экспорт сохранённого проекта сохраняет выбранные материалы и политику
источников; исправные ручные замены заново не подбираются.

Рядом с MP4 сохраняются `.stocks.txt` и `.stocks.json`: авторы, источник, лицензия
и изменения каждого использованного материала. При передаче ролика сохраняйте
эти сведения и выполняйте условия указанных лицензий. Архивные материалы нужно
обозначать в сценарии; наличие похожего кадра не подтверждает конкретное событие.

Commons поддерживает CC0, public domain и CC BY; SA/NC/ND и неизвестные условия
отклоняются. NASA принимается только при явных подходящих условиях конкретного
материала, поэтому многие результаты не будут доступны. Coverr используется для
видео. Источники, отключённые галочками, не используются даже из кэша.

В поле **«Скачивание и нарезка»** можно вручную вводить положительное целое
число без верхнего потолка приложения. Оно независимо от числа задач подбора
и рендеров; реально работают только имеющиеся задачи. Ограничения провайдеров,
24-часовой кэш поиска и паузы после429 сохраняются. Это не обход квот API.
