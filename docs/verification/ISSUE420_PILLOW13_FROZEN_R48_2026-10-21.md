# NewsFlow Issue #420 — verified Pillow 13 / ONNX CLIP / Frozen Core r48

Verified on 2026-10-21. Source branch `fix/security-pillow-onnx-clip`, PR #423.

## Root cause and correction
- `fastembed==0.8.0` and `rembg==2.0.84` capped Pillow below 13. Their resolver constraints prevented upgrading away from reported Pillow 12.3.0 CVEs.
- The existing runtime only used FastEmbed's fixed Qdrant ViT-B/32 vision/text CLIP pair. Replaced this narrow encoder use with `scriptor/onnx_clip.py` over supported ONNX Runtime, Hugging Face Hub and Tokenizers. Removed unused rembg runtime package; no production Python callsites imported it.
- Production/test hashed locks regenerated by GitHub Actions, Pillow `13.0.0`; both dependency audit and pip hash installation pass. Original semantic-index vector dimensions and cache model IDs remain unchanged.
