# Footage V3 implementation and verification plan

**Goal:** scene-local, bounded footage selection with explicit person evidence and topical fallback, preserving the existing montage diversity contract.
**Base:** `43dd0709d7341eb79b308303031b5f3a47fd3ebc` (origin/main fetched 2026-10-15).
**Branch:** `codex/footage-semantic-person-fallback-v3`.
**Spec:** owner-supplied NewsFlow footage V3; no main merge, production writes, paid calls, external footage downloads or Frozen/EXE rebuild.

## Design and established causes

Keep the existing batch retrieval, fallback enums, six-second grid, renderer, queue reservations and duration-based fast-reuse target. Add lightweight scene intent to the existing planner and an optional diagnostic field to saved clips. Names/paths are retrieval hints; only explicit signature- and interval-bound curated evidence can establish a person match. No new face recognition model is claimed.

Confirmed by source inspection: `fallback_visual_query` uses substring matches; `fallback_scene_plan` prepends the title to every sentence; `mark_used` evicts the full vector corpus; search rebuilds metadata and runs a Python query-by-clip loop; the last visual-continuity rescue is deliberately topic-agnostic and can bypass semantic constraints. Reproduce each changed behavior before implementation.

## Evaluation fixed before implementation

Mandatory lexical cases must have zero specified gross contradictions. Metadata/curated unit tests are not visual identity acceptance. Existing hard diversity assertions must stay intact. On deterministic suitable pools compare distinct clips/families, adjacent repeats, repeated sequences, opening overlap and duration target under fixed seeds/history; report unavailable metrics rather than inventing historical mechanisms. Report median and min/max of five performance repeats with equal corpus/query workload and cold/warm state; a synthetic speedup does not establish end-to-end user speedup.
