# Performance baselines

`../performance-baselines.json` is a reviewed, versioned policy file for
deterministic local NewsFlow paths. The known-good observations are reference
points; the warning and hard limits are intentionally wider to avoid flaky
Windows CI or shared-disk failures. A warning is diagnostic, while a hard
regression fails the relevant test.

The suite does not call a provider or use production data. Its real FFmpeg lane
uses the synthetic media generated by the existing montage benchmark.
